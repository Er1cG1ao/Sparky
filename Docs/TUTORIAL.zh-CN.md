# Sparky 使用教程

[English](TUTORIAL.md) · **简体中文** · [返回首页](../README.zh-CN.md)

## 登录与读取联系人

在“设置”选择“打开登录窗口”，完成抖音登录及网页要求的验证。Sparky 会等待聊天页就绪并识别到账号，再自动收起窗口、读取联系人。等待登录最长五分钟；关闭登录窗口或点击“取消登录”可以中止。

会话行可能先出现，昵称和头像稍后才加载。Sparky 会等待每屏资料稳定后再滚动，虚拟列表后续加载的会话也会经过同样检查。昵称缺失，或显示较长的数字占位且没有头像时，会继续等待。读取的是头像地址，不要求图片下载成功；有昵称但没有支持的头像地址的联系人仍可使用。

如果资料一直没有就绪，会等待后从头补读一次；失败时不替换同账号已有联系人和选择。扫描有时间上限，不会无限重试。网页恢复后也可手动点击“刷新账号与联系人”。

列表来自已有会话，支持群聊，但可能不包含折叠或陌生人列表。头像按需加载；无法加载时显示姓名首字或群聊图标。

## 选择好友与切换账号

在“联系人”搜索用户或群聊，勾选需要发送的会话。点击联系人行内任意位置即可切换选择；可在列表上方切换“全部／已选”。“全选当前列表”和“取消选择”只作用于当前筛选结果。

选择按稳定的抖音账号 UID 和会话 ID 保存，退出登录或重启不会清除。再次登录并完成抓取后，会恢复本次列表中能找到的已选会话。某次未读到的会话仍保留在记忆中，后续抓取到时再恢复；主动勾选或取消会更新这份记忆。

切换账号时，先在“设置”或左下角用户名旁退出登录，再登录另一个账号。退出会清除本应用的 WebKit 登录状态、当前账号和联系人列表，并暂停定时计划；各账号的好友选择、消息模板和发送记录保留，不影响手机或 Safari 的登录。

操作进行中不可退出登录。如果清理登录数据时应用中断，下次启动会继续清理，完成前阻止重新连接或发送。切换为不同账号会关闭旧计划；退出时暂停的计划在重新登录后也保持关闭。请核对恢复的选择后手动开启。

升级会迁移当前账号已经保存的选择；旧版本已经清除的选择无法恢复。

## 设置消息与每日时间

在“发送计划”填写单行消息，最多 **500 个 UTF-16 代码单元**，设置时间并开启定时。建议先用自己的测试会话执行一次“立即执行…”，核对名单，并在发送后检查实际聊天记录。

- 定时使用 Mac 当前时区。应用需保持运行，不会唤醒休眠中的 Mac。
- 唤醒后可补发当日尚未执行的计划，不重放前几天错过的任务。
- 开启计划或修改时间时，如果今天的时间已经过去，会从明天开始。
- 手动执行也占用当天的自动任务名额，避免再次自动发送；主动再次确认仍可执行新一批手动任务。
- 停止任务会阻止后续联系人发送，等待当前会话结束。
- 清空发送记录不会重新开启今天的定时任务。

Sparky 使用单个 WebKit 页面逐人发送。触发前检查账号、收件人和草稿，不覆盖不同内容的已有草稿，每次只触发一次发送。实际点击之间至少间隔一秒，等待回执最多约十二秒；网络确认较慢时不叠加固定冷却。

## 理解发送结果

发送记录按日期分组，展开一条记录可查看结果依据和可用的消息 ID。

| 状态 | 含义 |
| --- | --- |
| 服务器确认 | 点击后发起的发送请求获得成功回执，不代表送达、已读或火花更新。 |
| 页面确认 | 出现了新的对应自发消息，输入框清空，但未捕获服务器确认。 |
| 结果待确认 | 可能已发出，但证据不足，或任务在发送阶段中断。 |
| 服务器拒绝 | 服务器拒绝本次发送，不会自动重试。 |
| 未发送／已取消 | 尚未触发发送，或后续任务已取消。 |

回执关联依赖当前页面中的请求时序，不能保证端到端送达。页面确认和结果待确认应先用手机核实，再决定是否手动重发。任务中断后会保留记录，不自动重放发送。

## 窗口与开机启动

设置按“抖音账号”“通用”“诊断”分组；展开“运行日志”可查看及复制诊断信息。

窗口采用通顶的左右两栏，不再保留单独的工具栏横条。点击应用名称旁的侧栏按钮可折叠为图标栏，再次点击恢复文字。悬停图标可查看名称；底部保留账号和退出登录入口，展开状态会在下次启动时恢复。侧栏使用窗口背后的模糊材质；系统开启“减少透明度”时自动使用实色。

主窗口打开时显示 Dock 图标并支持 ⌘Tab。点击红色关闭按钮或按 ⌘W 会隐藏 Dock 图标，保留菜单栏运行；从菜单栏可以再次打开。最小化时保留 Dock 图标。

先将应用移入“应用程序”，再在设置中开启“登录 Mac 时启动 Sparky”。macOS 可能要求在“系统设置 → 通用 → 登录项”中批准。退出 Sparky 会停止调度。

## 本地数据与隐私

设置、账号选择及最近 **2,000 条发送元数据记录**保存在：

```text
~/Library/Application Support/Spark/state.json
```

沿用旧目录及应用标识是为了兼容升级。设置包含消息模板，单条历史记录不额外保存消息正文；状态文件仅当前用户可读写。侧栏折叠状态单独保存在 macOS 偏好设置中。登录数据由系统 WebKit 管理，不导出登录 Cookie，也没有额外上传服务器。

头像从支持的抖音／字节 HTTPS CDN 下载，不附带登录 Cookie，并限制跨站重定向。仅在以下目录缓存缩略图：

```text
~/Library/Caches/Sparky/Avatars
```

缓存约保留最近 512 张缩略图，三十天后重新获取。不支持的地址或下载失败会使用占位图，不影响发送。

本应用依赖抖音网页聊天，页面变化、验证或站点限制都可能造成中断。请勿在公开 Issue 中上传账号数据、登录 Cookie 或私人聊天截图。
